# mochalate.yazi

A Yazi flavor based on [mochalate-theme/nvim](https://github.com/mochalate-theme/nvim), a cozy fusion of
gruvbox warmth and catppuccin softness in mochalate tones.

## Installation

```bash
# Via ya package manager
ya pkg add mochalate-theme/yazi
```

Or manually clone this repository into your Yazi flavors directory:

```bash
git clone https://github.com/mochalate-theme/yazi ~/.config/yazi/flavors/mochalate.yazi
```

## Usage

Set the content of your `theme.toml` to enable it as your dark flavor:

```toml
[flavor]
dark = "mochalate"
```

Make sure your `theme.toml` doesn't contain anything other than `[flavor]`, unless you want to override certain styles of this flavor.
